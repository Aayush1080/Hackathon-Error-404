# Hackathon-Error-404
MoriSafe includes an interactive map that allows administrators to monitor reported incidents and nearby emergency services across Mauritius.
Features
- Displays reported incidents using category-based icons and colours.
- Shows police stations, hospitals, clinics and fire stations.
- Uses different marker colours to indicate incident status.
- Allows administrators to filter incidents by status and emergency services by category.
- Displays incident and location details when markers are selected.
- Allows administrators to select an incident for review.
Technologies
- React
- React Hooks
- Leaflet
- OpenStreetMap
- Inline SVG icons
- JSON location dataset (places.json)
Main Files
- icons.js – Contains map icons, colours and helper functions.
- places.json – Stores emergency service locations across Mauritius.
- AdminMap.jsx – Handles the interactive administrator map.
Purpose
To provide administrators with a centralised map for monitoring incidents and identifying nearby emergency services across Mauritius.
